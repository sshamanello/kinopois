## Architecture Overview

Kinopois is a CLI tool for downloading movie posters from Kinopoisk.dev API and creating 2x2 collages. The architecture follows a modular design:

- **CLI Layer** (`cli.py`): Click-based commands with dry-run support, validation, and status reporting
- **Data Layer** (`database.py`): SQLite with Movie/Collage models, batch operations with transactions/rollback
- **Scraper Layer** (`scraper.py`): Kinopoisk API client with rate limiting, resume capability, SSL handling via certifi
- **Processing Layer** (`processor.py`, `collage.py`, `marker.py`): Data cleaning, collage creation, watermarking
- **Export Layer** (`export.py`): Pinterest CSV and n8n JSON formats with metadata
- **Support**: `config.py` (settings), `logger.py` (file logging), `utils.py` (utilities)
- **Interactive**: `interactive.py` (questionary-based TUI)

### Data Flow

1. **Download**: `KinopoiskScraper.fetch_movies()` → `download_and_save()` → `Database.add_movies_batch()`
2. **Collages**: `create_collages()` reads movies grouped by genre → `CollageCreator.create_collage()` → extracts metadata (dimensions, file size, color palette) → `Database.add_collage()`
3. **Export**: `export_for_n8n_json()` reads collages → enriches with tags/boards → outputs JSON array

### Key Design Decisions

- **Database**: SQLite with automatic migration for new columns (width, height, file_size, color_palette in collages table)
- **Rate Limiting**: 3 req/sec with exponential backoff (1s → 2s → 4s → max 60s)
- **Resume**: Progress tracked in `data/progress.json` (last_page, downloaded_count)
- **SSL**: Uses certifi certificate bundle; custom SSLAdapter for legacy server compatibility
- **Batch Operations**: `executemany()` with BEGIN TRANSACTION/COMMIT, rollback on error
- **Logging**: File-based (`data/kinopois.log`) with structured levels, operation tracking, statistics

## Development Commands

```bash
# Install
pip install -e .

# Run tests
pytest

# Lint
black kinopois/
ruff check kinopois/

# CLI usage
kinopois download --limit 200 --resume          # Download with resume
kinopois download --limit 10 --dry-run          # Dry-run mode
kinopois collage --dry-run                       # Preview collages
kinopois export --format n8n-json                # Export JSON for n8n
kinopois status                                   # Show statistics and recommendations
kinopois run --all --dry-run                     # Simulate full pipeline
```

## Configuration

- `.env` file: `KINOPOISK_API_KEY`, `DATA_DIR`, `RATE_LIMIT_RPS` (default: 3.0)
- `config.py`: Settings loaded from environment with defaults
- Rate limiting parameters: `rate_limit_retry_attempts`, `rate_limit_initial_delay`, `rate_limit_max_delay`, `rate_limit_backoff_multiplier`

## Important Patterns

### Adding New Export Formats

1. Add function to `export.py` with signature: `export_format_name(db: Database, output_path: Optional[Path] = None) -> Path`
2. Add format choice to `--format` option in `cli.py` export command
3. Use `Progress` from rich for user feedback

### Database Migrations

The `create_tables()` method in `database.py` automatically adds new columns:
```python
cursor.execute("PRAGMA table_info(collages)")
existing_columns = {col[1] for col in cursor.fetchall()}
for col_name, col_type in new_columns.items():
    if col_name not in existing_columns:
        cursor.execute(f"ALTER TABLE collages ADD COLUMN {col_name} {col_type}")
```

### Logger Usage

```python
from kinopois.logger import get_logger
logger = get_logger()
logger.info("Operation started")
logger.error("Error occurred", exc_info=True)  # With traceback
logger.log_ssl_error(url, exception)
logger.increment_stat("movies_downloaded")
```

### Dry-Run Implementation

Pattern: Add `dry_run: bool = False` parameter, prepend operations with `[DRY RUN]`, skip file/database writes:
```python
if dry_run:
    console.print("[yellow][DRY RUN] Would create: {filename}[/yellow]")
    return
# Actual operation
```

## n8n Integration

Export format `n8n-json` produces array of objects:
```json
[{
  "id": 1,
  "image_url": "https://...",
  "title": "4 мелодрамы...",
  "description": "...",
  "board": "Мелодрамы",
  "genre": "мелодрама",
  "file_size": 123456,
  "width": 1000,
  "height": 1500,
  "films": ["Фильм 1", "Фильм 2", ...],
  "color_palette": ["#1a2b3c", ...],
  "created_at": "2025-02-03T15:30:00",
  "tags": ["фильмы", "подборка", "мелодрама"]
}]
```

Tags are generated by `generate_tags()` in `export.py` based on genre mapping.
